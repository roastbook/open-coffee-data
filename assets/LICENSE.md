# Licence: assets/

Every file in `assets/` has its own licence. Each folder has a `LICENSE.md` with one table row per file: file name, licence (SPDX identifier), author and source URL. `scripts/validate.sh` fails when a file has no row.

Accepted licences: CC0-1.0, PDM-1.0, CC-BY-x.0 and CC-BY-SA-x.0. When you reuse an image, credit its author and licence as listed, not “Roastbook Open Coffee”. Images licensed CC-BY-SA keep that licence; they are not relicensed under the dataset's CC BY 4.0.

Folders:

- [`coffee-places/`](coffee-places/LICENSE.md): photos of coffee places
